# 16:04  qa → orchestrator  |  TAM-24 (P3-11)
- Zrobione: Test wariantu C (link Google Maps bez `origin`) na telefonie (Android 13, Mapy 26.47), bez kodu aplikacji
  i bez kosztów. We wszystkich trybach (auto, komunikacja, pieszo) Mapy same ustawiają start „Twoja lokalizacja”
  i pokazują trasę. Bez zgody lub przy wyłączonej lokalizacji Mapy same pytają albo dają wybrać start, a cel
  zostaje. Porównanie z `origin` = nocleg działa. Uzupełnienie: przy wyłączonej aplikacji Map system pokazuje wybór
  przeglądarki. Google Maps web wyznacza trasę „Z: Twoja lokalizacja” z zachowanym trybem. Inne aplikacje mapowe
  nie są proponowane. Telefon przywrócony do stanu sprzed testu (Mapy włączone, uprawnienia, lokalizacja), zwolniony.
- Artefakty: `docs/qa/QA-TAM-24-maps-bez-origin.md`, `docs/open-questions.md` (Q1 odpowiedziane)
- Decyzje: **właściciel 2026-11-25: wariant C (link bez origin, bez uprawnień lokalizacji) dla MVP** (Q1)
