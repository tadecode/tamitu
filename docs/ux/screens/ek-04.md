# Ekran: EK-04 Lista planów (ekran główny)

- Status: szkic (do uzgodnienia z architektem)
- Historyjki: US-008
- Autor: ux · Data: 2026-11-16 · Wersja: 0.1
- Makieta: [`mockups/ek-04.html`](../mockups/ek-04.html)

## Cel
Zobaczyć zapisane plany i otworzyć jeden z nich albo zacząć nową podróż.

## Wejście i wyjście
- Skąd: EK-01, EK-02 (po logowaniu), EK-03, powrót z EK-08 / EK-11 / EK-12.
- Dokąd: karta planu → EK-08; „Nowa podróż" → EK-05; ikona ustawień → EK-12.
- Wstecz systemowe: zamyka aplikację.

## Wzorzec i komponenty
- Wzorzec: lista i szczegóły (pkt 1), pusty stan (pkt 3), ładowanie (pkt 4), błąd z ponowieniem (pkt 5).
- Komponenty: CMP-01 (główny), CMP-12 (karta planu), CMP-03, CMP-13, CMP-14, CMP-17 (szkielet), CMP-18.

## Układ
Pasek górny „Twoje podróże" + `settings`; lista kart (8 dp odstępu) od najnowszego; FAB w prawym dolnym rogu; dolny odstęp listy = FAB + 16 dp. Medium/expanded: lista maks. 600 dp, wyśrodkowana (kierunek lista–szczegóły poza MVP).

## Dane na ekranie
| Pole | Źródło | Wymagane | Uwagi |
|---|---|---|---|
| Cel podróży | lokalnie `trips.destination` | tak | ≤ 80 zn.; w języku wpisanym przez użytkownika; 2 linie, potem wielokropek (D4) |
| Liczba dni | `trips.days_count` | tak | liczba mnoga wg języka UI |
| Sposób dojazdu | `trips.arrival_mode` | tak | ikona + tekst |
| Data utworzenia | `trips.created_at` | tak | format lokalny języka UI |
| Kolejność | `ORDER BY created_at DESC` | – | |

## Stany
| Stan | Co widzi użytkownik | Teksty |
|---|---|---|
| Ładowanie | szkielet 3 kart po 300 ms; FAB ukryty | `commonLoadingLabel` |
| Pusty | CMP-18 „Pusty" z przyciskiem wypełnionym „Nowa podróż", pod nim CMP-13 o przechowywaniu na urządzeniu (U9); FAB ukryty | `planListEmptyTitle`, `planListEmptyBody`, `planListNewTrip`, `planListDeviceOnlyNotice` |
| Sukces | karty planów, FAB | `planListTitle`, `planListDays`, `planListArrivalFlight`, `planListArrivalCar`, `planListCreatedOn` |
| Błąd | CMP-18 „Błąd" + „Spróbuj ponownie" (błąd odczytu bazy) | `planListLoadErrorTitle`, `planListLoadErrorBody`, `commonRetry` |
| Brak sieci | bez zmian (ekran działa offline) | – |
| Po usunięciu planu | snackbar nad FAB | `planDeletedSnack` |

## Dostępność
- Fokus: tytuł → ustawienia → komunikat → karty (od góry) → FAB.
- Karta jako jeden element: „Lizbona, 4 dni, lot, utworzono 12 maja 2027, przycisk".
- Cele: karta ≥ 72 dp, FAB 56 dp, ikona 48 dp.
- Skalowanie: przy 200% karty rosną, FAB zawija tekst (makieta: przełącznik „Tekst").

## Prywatność i zgody
Pokazuje dane podróży (D4) z bazy lokalnej konta; inne konto ich nie widzi (US-008). Przegląd security: nie (bez zmian zakresu danych).

## Uzgodnienie z architektem
Do potwierdzenia: brak potrzeby paginacji (U13 – brak limitu, mała liczba planów).
