# Ekran: EK-06 Zgoda na AI

- Status: szkic – **wymaga przeglądu security i [PRAWNIK]** (treść zgody)
- Historyjki: US-003, US-005
- Autor: ux · Data: 2026-11-16 · Wersja: 0.1
- Makieta: [`mockups/ek-06.html`](../mockups/ek-06.html)

## Cel
Świadomie zdecydować, czy dane podróży mogą zostać wysłane do usługi AI, aby ułożyć plan.

## Wejście i wyjście
- Skąd: EK-05 („Generuj plan" bez aktualnej zgody); EK-13 („Wyraź zgodę"); EK-05 komunikat „Wyraź zgodę".
- Dokąd: „Zgadzam się" → zapis → EK-07 (z EK-05) lub EK-13 (z Ustawień); „Nie zgadzam się" → powrót (EK-05 z danymi / EK-13), nic nie wysłane, limit niezużyty.
- Wstecz systemowe i strzałka = „Nie zgadzam się" (bez zapisu odmowy jako zgody `granted=false` – do potwierdzenia z security; propozycja: odmowa przy pierwszym pytaniu nie tworzy rekordu).

## Wzorzec i komponenty
- Wzorzec: zgody i uprawnienia (pkt 8).
- Komponenty: CMP-01 (ze wstecz), CMP-13 (ostrzeżenie o danych wrażliwych), CMP-02 ×2 **outlined, ten sam styl** („Zgadzam się", „Nie zgadzam się"), CMP-17 (w przycisku), CMP-14.
- **Bez checkboxa** (decyzja = przycisk; odmowa równie łatwa).

## Układ
Pełny ekran, treść przewijana: tytuł w pasku; wstęp; lista „Co wysyłamy" / „Czego nie wysyłamy" (punkty z ikonami `check` / brak, zwykły tekst); „Kto otrzymuje"; „Pamiętaj" (błędy AI); ostrzeżenie o danych wrażliwych (CMP-13); informacja o wycofaniu; link do polityki. Na dole, przyklejone: dwa przyciski na pełną szerokość, jeden pod drugim, ta sama waga (outlined), kolejność: „Zgadzam się", „Nie zgadzam się" (do decyzji security, czy kolejność alternować nie trzeba – propozycja: stała).
